# Causeway grassy walking edge

The user approved the preview in `exec-123701b0-b4e0-4831-a35f-459718987dbc.png` and requested application. This implementation adds a narrow, continuous meadow-green grass rim with modest tufts to Causeway's existing walking surface. It preserves the original rock body and earlier cave/background decisions.

The built-in image-generation tool produced `Assets/Resources/Terrain/CausewayGrass/GrassEdge.png` as an isolated transparent production asset, using the approved preview as style reference. Native source pixels were copied unchanged. See `PROMPT.md`. The preview itself is not used as a game texture. Existing accepted art sources and their imports are unchanged.

`MraTerrain.CausewayGrass.cs` creates one managed mesh per eligible terrain piece. Texture sampling follows cumulative slope distance; mirrored horizontal wrapping gives continuous joins without modifying source pixels. Grass blades remain upright. Narrow fades finish cliff ends; cave-mouth masks exclude the protected entrance/rim area. The generated objects have no colliders, use the existing terrain material, and are destroyed/rebuilt with their owning terrain. Only the exact Causeway scene and upper-route predicate are eligible.

4K sizing: the closest camera's orthographic half-height is 5, so 2160 / 10 = 216 screen pixels per world unit. Native/imported source is 2172 × 724, sampled at 362 pixels per unit over a six-unit span. Accounting for vertical-blade shear on the maximum 1.2 grade gives a conservative minimum of 272.23 pixels/unit; the required full-image size is ceil(216 × 6 × sqrt(1 + 1.2 / sqrt(1 + 1.2²)))) × its corresponding height = **1724 × 575**. Alpha crop coordinates exclude unused transparent canvas, without cropping or resampling the source file. Mirrored U, clamped V, bilinear filtering, mipmaps and aniso 4 are configured; the Windows Editor import is uncompressed with NPOT resizing disabled.

Verification: compilation passed. Real Play-mode movement advanced 120 rendered frames and 10.57 world units across the slope with zero errors. Native 4K and 1080p captures are in `Play/`. Before/after protected image regions at all four cave mouths have zero RGB difference, as does the measured lower rock-body region. All 13 saved scene hashes remain unchanged; saves and Editor settings were restored. See `QA.json`. This is Windows Editor validation, not standalone/console, physical-controller or 60-FPS hardware qualification. Supported targets remain Windows PC, PS5, Xbox Series X/S and Switch 2 handheld/docked.
